A program that writes a single one-line, one-star review from a houseplant about its human owner — a sharp, funny plant's-eye complaint — to `/output/entry.txt`.

The review: a houseplant watches its owner lovingly water the plastic succulent beside it every morning while never watering the real plant once.

## Run it

```sh
python3 main.py
```
